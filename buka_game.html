Pusat Peluncur EduQuest AR

Platform Game Edukasi Gestur AR & Layar Sentuh Interaktif untuk SD Kelas 1-6 dan Interactive Flat Panel (IFP) Android.

💻 Komputer / Laptop PC

Cukup klik ganda start.bat di folder ini. Server otomatis berjalan di http://localhost:3000 meskipun PC Anda tidak memiliki Node.js!

Buka http://localhost:3000
📺 Interactive Flat Panel Android

Buka browser Google Chrome di Android IFP Anda. Buka tautan game, lalu klik "+ Pasang Aplikasi (PWA)" agar terpasang di beranda Android tanpa browser bar.

⚡ Buka Langsung (Dist)

Membuka berkas dist/index.html secara langsung. (Jika kamera/audio dibatasi oleh kebijakan keamanan browser lokal, gunakan start.bat).

Buka dist/index.html
📋 Panduan Singkat untuk Guru di Kelas:
  1. Bermain di Layar Panel Sentuh Android (IFP 65" - 86"): Sambungkan IFP ke Wi-Fi kelas. Buka browser Google Chrome di IFP dan pasang game sebagai PWA (layar penuh, orientasi horizontal otomatis). Semua fitur multi-touch 10 jari dan kamera AR langsung aktif!
  2. Bermain di Komputer Sekolah (Offline Penuh): Klik ganda berkas start.bat. Game akan segera membuka tab browser baru. Anda tidak perlu koneksi internet dan tidak perlu memasang Node.js.
  3. Kontrol Sentuh vs Kontrol Gerak (AR): Guru dan murid dapat berganti mode kapan saja antara Layar Sentuh (Touch), Gestur Kamera (AR), atau Mouse melalui tombol di pojok atas layar.
